# Unified Project Workspace

The Project Workspace presents the normal long-form narration path on one page:

1. Script & Project
2. Voice & Preview
3. Render
4. Review
5. Export

It keeps the existing OmniVoice project, verification, checkpoint/resume, quality preset, queue and history services underneath the UI. The visible project selector remains the source of truth. Section selection uses a checklist with titles and status instead of a comma-separated ID textbox.

The existing specialist tools remain available under Library and Settings for advanced workflows.
