# Project Status Queue UX

The Project Queue browser defaults to `PENDING` and `GENERATING`, hides `DONE` unless explicitly enabled, and excludes projects already present in `project-queue.json`.

Dropdown labels include render status and section progress, for example `[PENDING 3/11] Video A`.

For large workspaces, `Add ALL filtered projects using saved settings` queues every visible candidate using that project's own saved Studio voice, variant, and language settings.
